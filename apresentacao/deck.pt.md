# EGOS × Hacash

## 1. O que oferecemos

O EGOS é um projeto brasileiro de sistemas de IA. Nossa regra: medir antes de afirmar.

Oferecemos três contribuições pequenas e abertas: documentação, um mapa de issues para começar e um conector de IA somente leitura para o nó.

## 2. O que vimos na comunidade

Medido em 21/10/2026:

- Conversa: Discord, Telegram, X.
- Documentação: 3 sites, 2 repositórios.
- 20 de 55 rotas da API fora da doc v2.
- 55 issues abertas, nenhuma com etiqueta.

A página da HacashDAO já pede para reunir esses grupos.

## 3. O que já existe

- Base de conhecimento em inglês e português: 11 seções, toda afirmação com data e fonte.
- Servidor MCP: 5 consultas, 62 testes, conferido ao vivo.
- Nó 1.2.5 sincronizado: bloco 792.727.
- Mapa da API: 55 rotas com origem e classe de risco.

## 4. Como funciona

```
Fullnode Hacash 1.2.5
(o seu nó ou um nó da comunidade)
        │
        ▼
Servidor MCP: 5 consultas somente leitura
altura · oferta · saldo · diamante · transação
        │
        ▼
Cliente de IA
Claude Code, Claude Desktop, Codex, agentes locais
```

Cada resposta diz de qual nó e de qual rota veio. Entrada inválida para antes de chegar ao nó. Erro volta como erro, nunca como dado inventado.

## 5. O que propomos

Três contribuições pequenas:

1. Documentação em inglês, chinês e turco, começando pelo mapa de rotas da API.
2. Mapa das 55 issues abertas para quem chega, com etiquetas sugeridas.
3. O servidor MCP (MIT) num repositório oficial da Hacash, se os mantenedores quiserem.

## 6. O que não fazemos

- Não guardamos chave privada.
- Não assinamos nem transmitimos transações.
- Não criamos token nem pedimos fundos.

O MCP é só leitura: chave privada nunca deve sair da máquina de ninguém. Sem exclusividade, sem sistema paralelo de tarefas.

## 7. Como começa

1. Os mantenedores revisam esta oferta e escolhem o canal.
2. Um pull request pequeno.
3. Iteramos em público, seguindo o fluxo da HIP-12; GitHub e HIPs seguem como fonte.
